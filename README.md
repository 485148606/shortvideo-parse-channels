# 短视频平台解析通道（shortvideo-parse-channels）

**抖音 / 快手 / 小红书 / 哔哩哔哩** 四个短视频平台的分享链接解析通道与反爬应对。当需要从分享链接取回视频直链、封面、文案，或遇到「接口返回 200 但没数据」「被限流」「解析失败」「需要签名」这类问题时使用。也适用于给小程序 / App 做视频提取后端。

触发词：解析抖音、去水印、视频提取、快手解析、小红书解析、ttwid、a_bogus、APOLLO_STATE。

> **核心结论：三个平台的失败原因都不是"需要逆向签名"，而是缺一个 cookie 或没重试。**
> 四个平台的解析路线全部实测验证过（2026-09）。

## 速查表

| 平台 | 通道 | 稳定性 | 一句话要点 |
|---|---|---|---|
| 哔哩哔哩 | 官方 API | ★★★★★ | 必须带 `Referer: https://www.bilibili.com` |
| 抖音 | 官方 web API（主）+ iesdouyin SSR（兜底） | ★★★★★ | **必须带 `ttwid` cookie** |
| 快手 | `www.kuaishou.com/short-video/{id}` SSR | ★★★ | 会风控（status=2），有移动端兜底 |
| 小红书 | 页面 SSR | ★★ | **必须带用户 Cookie（a1 / web_session）** |

## 何时使用

- 要从抖音 / 快手 / 小红书 / B站分享链接提取视频直链、文案、封面
- 接口返回 200 但 body 是空的、或页面里拿不到数据
- 做视频提取类小程序 / App 的后端

完整通道细节（每平台的请求模板、cookie 获取、风控应对、兜底链路）见 [`SKILL.md`](SKILL.md)。
